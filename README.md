# Leaf Classifier

A browser-based leaf classifier using the rear camera or an uploaded photo. The app runs `leaf_model.onnx` in the browser with ONNX Runtime Web.

## Live app

https://mesklashin.github.io/mlr-ex08/

## Run locally

Serve this folder over HTTP or HTTPS and open `index.html`. Camera access requires HTTPS (or localhost). The page loads ONNX Runtime Web and the QR-code generator from jsDelivr.
